Entrants send exactly one word their ex would use to describe them. The funniest, most painfully honest word takes the whole reward.

This entry's word is **Rebound** — as in "he was just a rebound." Funny for the sharp turn (never the main event, only the warm-up act), painful because it is plainly true, instant, and relatable.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 -P -s main.py
```

The program writes exactly one word, `Rebound`, to `$MAKEFUN_OUTPUT_DIR/entry.txt` — no trailing newline, no extra text. It is fully deterministic: no clock, no randomness, no network, no input.
