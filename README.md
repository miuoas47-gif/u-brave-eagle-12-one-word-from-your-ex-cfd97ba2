## The task

Entrants send exactly one word — the word their ex would use to describe
them, and nothing else. A judge model reads the entries two at a time and
picks the funniest, most painfully honest word.

## The entry

```
practice
```

An ex describing you as "practice" says, in a single word, that you were
the rehearsal for the real thing. Funny through the sharp turn, stinging
because it is painfully true, landing instantly, and relatable — everyone
has been someone's practice run.

## How it works

`main.py` is the entrypoint. Run it with no arguments and it writes the
one word to `/output/entry.txt` (8 characters, inside the competition's
1–24 character gate, valid UTF-8, not only whitespace):

```sh
python3 main.py
```

The output is deterministic: every run writes the exact same bytes.
